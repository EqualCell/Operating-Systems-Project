# Implementation inventory (2026-11-17)

Starting revision: 19a6e69; origin verified as EqualCell/Operating-Systems-Project;
branch rebuild/crash-safe-agent; initially clean tree; no AGENTS.md found.

Working baseline: full-width kernel keys, copied arguments, sleep-lock effect
serialization, reserved completion block, bounded APPEND/CREATE, log crash
hooks, QEMU bridge, deterministic planner, independent image reader, existing
crash sweeps and mutation harness. Initial host suite: 23 tests passed.
Baseline build succeeds with installed RISC-V GCC and QEMU on Ubuntu 26.04.1.
Detailed fresh results are generated by tests/run_all.py (historical evidence
is not evidence for the new security implementation).

Defects found by inspection: CREATE's namei/create pair could accept an inode
created by ordinary O_CREATE; classification used shared counters; allocation
of an indirect block could survive a zero-progress append; journal ignored
malformed records anywhere and appended after an unterminated tail; log names
collided between bridge instances; Agent could return OK after a final error.
Foundation repairs and regression tests address these before authorization.

Missing at baseline: authority separation, persistent grants, revoke, stable
protected identity/version, kernel bypass enforcement, exact security bindings,
and host grant/recovery protocol. Legacy FNV binding is diagnostic only.

Obsolete documentation: the upstream README is retained as upstream README;
older project docs describe deduplication alone as exactly-once and describe
kernel enforcement as future work. Current README.md/design.md/demo.md are the
normative entry points; legacy reports remain labeled historical.

Current implementation adds the authority bit, 32 retained single-use grants,
exact request binding, inode pinning, persistent object versions, revoke/status,
controller and agent recovery, and adversarial security/crash/mutation tests.
See design.md for the normative implemented contract and evidence/summary.md
at repository root for final fresh results. Duplicate project summaries and
legacy contract/overview/result documents were consolidated into README.md,
design.md, demo.md and testing.md; historical debug notes remain under history/.
